# DocuCore 360 — project description

## Repository About description

A privacy-focused PDF, image and document workspace with 29 browser-based tools, multilingual OCR, editable drafts, private file versions and personal profiles. Built with Next.js, React, TypeScript and PostgreSQL.

## Full description

DocuCore 360 brings everyday document work into one personal web workspace. Users can read, merge, split, annotate and organize PDFs, edit and convert images, recognize scanned text in seven languages, reconstruct supported Office documents and compare extracted text changes.

Most processing happens in the browser. Explicit saving adds documents to an account-owned library with folders, search, favorites and version history. Editable PDF drafts preserve project state across sessions, while opt-in autosave and revision checks help protect ongoing work. Personal profiles provide a photo, contact information and bio, with light, dark and system appearance settings.

The application combines a Next.js and React interface with PostgreSQL/Prisma metadata, private binary storage, secure account sessions and dedicated document workers. Operational tooling covers administration, SMTP account email, health checks, scheduled cleanup, Docker deployment and paired database/storage backups. Complex document fidelity remains best effort and is disclosed in the capability documentation.
